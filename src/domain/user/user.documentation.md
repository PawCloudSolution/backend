# User Domain Documentation

## 1. Что такое User

User — это доменная сущность, представляющая пользователя системы.
Является агрегатом, инкапсулирующим идентичность пользователя, его персональные данные, учетные данные и роль.

Ключевые характеристики:

- Имеет уникальную идентичность (UserIdValueObject)
- Содержит валидированные value objects (имя, email, username и т.д.)
- Управляет своей целостностью через фабричные методы и поведение
- Скрывает внутреннюю реализацию (все поля private)
- Изменение состояния возможно только через методы

Состав:

- id: UserIdValueObject — уникальный идентификатор
- name: NameValueObject — имя
- surname: SurnameValueObject — фамилия
- email: EmailValueObject — email
- username: UsernameValueObject — username
- role: UserRoleValueObject — роль
- hashedPassword: string — захешированный пароль
- phoneNumber: string | null — телефон (опционально)


## 2. Поведение User

Сущность управляет:

- созданием (register)
- восстановлением из хранилища (restore)
- доступом к данным (getters)
- проверкой ролей
- изменением состояния
- контролем прав (например, смена роли)
- сравнением по идентичности

Принципы:

- Любые изменения проходят через value objects
- Валидация делегирована value objects
- Бизнес-логика инкапсулирована внутри сущности


## 3. Public API

### 3.1 Фабричные методы

#### register(rawData: UserCreationRawData): User

Назначение:
Создание нового пользователя (новая сущность)

Реализация:

- Генерирует новый id через UserIdValueObject.generate()
- Создает value objects из raw данных
- Формирует props
- Возвращает новый экземпляр User


#### restore(rawData: UserRestoreRawData): User

Назначение:
Восстановление пользователя из хранилища

Реализация:

- Использует уже существующий id через UserIdValueObject.create()
- Создает value objects из raw данных
- Формирует props
- Возвращает новый экземпляр User

### 3.3 Проверка ролей

#### isRoleManager(): boolean

Назначение:
Проверка, является ли пользователь менеджером

Реализация:
Делегирует проверку в this.role.isRoleManager()


#### isEmployee(): boolean

Назначение:
Проверка, является ли пользователь сотрудником

Реализация:
Делегирует проверку в this.role.isEmployee()


#### isMember(): boolean

Назначение:
Проверка, является ли пользователь участником

Реализация:
Делегирует проверку в this.role.isMember()


### 3.4 Управление ролями

#### changeRoleBy(actor: User, newRole: UserRoleValueObject): void

Назначение:
Изменение роли сущности, которое инициирует *actor*

Реализация:

- Проверяет, что *actor* является менеджером
- Проверяет, что сущность не меняет роль сама себе
- Проверяет, что новая роль не равняется старой
- Если да — напрямую изменяет роль сущности
- Если нет - выкидывает соответствующую ошибку
