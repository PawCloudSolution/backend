# Paw Cloud Solution - Доменная Архитектура

Добро пожаловать в документацию по бизнес-логике платформы! 
Здесь описаны основные сущности системы (Агрегаты), их связи и бизнес-правила согласно подходу Domain-Driven Design (DDD).

Используйте Граф в Obsidian (`Cmd/Ctrl + G`), чтобы увидеть визуальные связи между всеми доменами.

## Ключевые домены:
- [[OrganizationApplication]] — Процесс онбординга и проверки новых Главных Управлений (HQ).
- [[Organization]] — Иерархия кинологических клубов, питомников и отделений (база для Multitenancy).
- [[User]] — Сотрудники и члены клубов, роли и доступы.
- [[Dog]] — Регистрация и управление собаками.
- [[Breed]] — Мультиязычный справочник пород.
